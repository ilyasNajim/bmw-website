## Overview

A single-page showroom concept inspired by BMW's iconic design and performance. Explore a selection of BMW models through a clean interface with interactive features and a responsive layout.

## Features

- 🚘 Interactive car catalogue with category filters
- 🎞️ Carousel navigation
- 📱 Responsive mobile menu
- ✨ Scroll-triggered effects and animated statistics
- 💬 Testimonial carousel
- ❓ Expandable FAQ section
- ✉️ Contact form powered by FormSubmit

## Technologies

**HTML5 · CSS3 · Vanilla JavaScript**

## Run Locally

```bash
git clone https://github.com/ilyasNajim/bmw-website.git
cd bmw-website
```

Open `index.html` in your browser.
