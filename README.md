## Overview

**BMW Website** is a front-end showroom concept inspired by BMW's design language, performance, and automotive identity.

The project presents a curated selection of BMW models in a visually engaging, single-page experience. It combines a responsive layout with interactive components and subtle animations to create a smooth and accessible browsing experience across desktop and mobile devices.

Developed with **HTML5, CSS3, and vanilla JavaScript**, the project demonstrates practical front-end development skills without relying on a JavaScript framework.

## Features

- **Interactive Vehicle Catalogue** — Browse a selection of BMW models through image-focused cards.
- **Category Filtering** — Filter vehicles by category for easier exploration.
- **Carousel Navigation** — Navigate through featured content using interactive carousels.
- **Responsive Navigation** — Mobile-friendly navigation menu for smaller screens.
- **Animated Statistics** — Dynamic counters that animate as part of the user experience.
- **Scroll-Triggered Effects** — Visual animations activated during page scrolling.
- **Testimonial Carousel** — Explore customer-style testimonials in a dedicated section.
- **Expandable FAQ** — Reveal answers through an interactive frequently asked questions section.
- **Contact Form** — Submit messages through a form connected to FormSubmit.
- **Responsive Layout** — Adapted for desktop, tablet, and mobile screens.

## Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Page structure and semantic content |
| CSS3 | Layout, styling, responsive design, and animations |
| Vanilla JavaScript | Filtering, carousels, navigation, counters, and interactive components |
| FormSubmit | Contact form submission handling |

## Getting Started

### Prerequisites

You only need a modern web browser. No framework installation or build process is required.

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/ilyasNajim/bmw-website.git
   ```

2. Open the project folder:

   ```bash
   cd bmw-website
   ```

3. Open `index.html` in your browser.

   Alternatively, use the **Live Server** extension in Visual Studio Code for local development.
