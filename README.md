## About the Project

BMW Experience is a single-page showroom concept designed to showcase selected BMW models through a clean interface, automotive imagery, and interactive front-end components.

Built with **HTML5, CSS3, and vanilla JavaScript**, the project focuses on responsive design, intuitive navigation, and an engaging browsing experience across desktop and mobile devices.

## Key Features

- **Vehicle Catalogue** — Browse selected BMW models.
- **Category Filters** — Explore vehicles by category.
- **Interactive Carousels** — Navigate featured content and testimonials.
- **Responsive Navigation** — Mobile-friendly menu.
- **Animated Statistics** — Dynamic numerical counters.
- **Scroll Effects** — Visual effects triggered while scrolling.
- **FAQ Section** — Expandable questions and answers.
- **Contact Form** — Form submission through FormSubmit.

## Getting Started

Clone the repository and open the project locally.

```bash
git clone https://github.com/ilyasNajim/bmw-website.git
cd bmw-website
```

Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.
